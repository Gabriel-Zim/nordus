# Nordus

Read [`AGENTS.md`](AGENTS.md) for how to work on this code.

If someone asked you to **install Nordus** (on their computer or on a server), follow [`INSTALL.md`](INSTALL.md): it
has the exact commands for macOS, Windows and a Linux VPS, and a checklist for agents at the end. Run the commands
yourself. On a server the installer stops at "Connect this Nordus to your account" with a link and a code: show both
to the person at once and wait; it continues by itself when they confirm in the browser. Finish by giving them the
address (`https://their-name.nordus.ai`) and telling them to choose "Entrar com Google" there.
